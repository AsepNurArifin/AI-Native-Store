# Audit Antislop 001: Frontend Toko Bu Ratna

Tanggal: 2026-09-14 · Mode: AFTER (audit pasca-redesign)
Skill yang dipakai: antislop (core), antislop-ui, antislop-copywriting, antislop-human, antislop-layoutmobile, antislop-code
Metode: scan statis grep atas seluruh `frontend/app`, pengukuran kontras via formula WCAG (canvas OKLCH -> sRGB), klik-tuntas browser di 390px / 512px / 820px / 1440px, uji keyboard dan zoom 200%.

Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

---

## Temuan ( bernomor, siap dipilih untuk perbaikan )

### HIGH ( Hard Gate )

**1. R-25 Kontras: `text-stone-400` pada teks kecil, rasio 2.48-2.52 : 1 ( butuh 4.5 )**
Label `text-xs font-semibold text-stone-400` di `admin/actions/[id].vue` ( Produk/Diskon/Periode ), `admin/analytics/index.vue` ( nomor urut, kategori, hint ), `admin/index.vue` ( label KPI "Koneksi backend", API ), dan breadcrumb `layouts/admin.vue` baris 171. Terukur: 2.52:1 di putih, 2.48:1 di stone-50. Gagal untuk normal text.
Perbaikan: ganti ke `text-stone-500` ( 4.80:1 di putih, 4.58:1 di stone-50, lolos ).

**2. R-25 Kontras: `text-clay-600` pada link teks kecil, rasio 3.87 : 1**
Link "Kembali" ( actions/[id], conversations/[id], customers/[id], orders/[id] ), "Lihat semua" / "Buka inventori stok" di dashboard, dan aksen "baru pesan." di `chat.vue` h1 ( 48px = large text, lolos 3:1, tapi link-link text-sm/text-xs gagal ).
Perbaikan: `text-clay-700` ( 5.37:1, lolos ) untuk semua link bawah 18px.

**3. R-25 Kontras: nomor stok menipis `text-amber-600`, rasio 3.19 : 1**
`admin/products/index.vue` baris 65. Dot amber + aria-label sudah benar ( sinyal bukan warna-saja ), tapi nilai numeriknya sendiri gagal 4.5:1 pada ukuran table-cell.
Perbaikan: `text-amber-700` ( 5.02:1, lolos ).

**4. R-03 Navigasi admin hilang total di mobile ( < 768px )**
`layouts/admin.vue` baris 5: sidebar `hidden md:flex` tanpa pengganti. Terukur di 390px: satu-satunya kontrol yang tersisa adalah logo "AI-Store" ( ke `/` ). Tombol Keluar ada di sidebar, jadi ikut hilang: user mobile tidak bisa logout, tidak bisa pindah halaman admin. Melanggar pola "Nav That Stays Desktop" sekaligus memutus semua nav item ( R-24 secara efektif di viewport sempit ).
Perbaikan: header mobile dengan tombol "Menu" berlabel yang membuka drawer sidebar ( closable Escape ), plus tombol Keluar reachable.

**5. R-27 Empty state hilang di 5 halaman tabel**
`orders`, `conversations`, `customers`, `audit`, `promotions`: saat data kosong / filter tanpa hasil, tbody kosong tanpa pesan. Hanya `actions` yang punya "Belum ada draft." `orders` juga tanpa loading state awal ( hanya error ); data seed kini ada ( 2 order ) tapi filter bisa menghasilkan nol.
Perbaikan: baris `<tr><td colspan=N>` "Belum ada X. [aksi mengisi]" per tabel; state "Memuat…" saat fetch awal.

**6. R-02 Em-dash tersisa di teks UI**
- `admin/actions/index.vue` baris 4: "Approve / reject — eksekusi hanya bila…"
- `admin/actions/[id].vue` baris 30 ( rentang tanggal ), baris 82 ( "Sudah diputuskan — read-only." )
- `admin/inventory/index.vue` baris 12 & `admin/promotions/index.vue` baris 12-13: option "— pilih —" dan "nama — harga"
- `admin/products/index.vue` baris 162: dialog confirm hapus
Perbaikan: titik, koma, titik dua, atau "s.d." untuk rentang.

### MEDIUM ( Purpose-Gate / C-2 )

**7. R-03 Tap target di bawah 44px di halaman chat**
Chip prompt terukur 29px, tombol Kirim 36px. `pages/chat.vue` chip `py-1.5 text-xs`.
Perbaikan: `py-2.5` ( atau min-h-[44px] ) pada chip; Kirim size lg.

**8. C-4 `error.vue` tidak ada**
404 / 500 memakai halaman default Nuxt tanpa layout toko. Jalur `/admin/xyz` yang salah tulis jatuh ke layar putih generik.
Perbaikan: `frontend/app/error.vue` dengan gaya nota ( motif identitas ), link kembali ke `/` dan `/admin`.

**9. C-2 Filter channel order tidak cocok dengan data**
Data seed memuat channel WHATSAPP ( terlihat di tabel ), tapi select filter hanya WEB / TELEGRAM. Pilih "Semua channel" lalu lihat baris WHATSAPP tanpa cara memfilternya.
Perbaikan: opsi WHATSAPP ditambahkan ( atau opsi dibangun dari data unik ).

**10. Konsistensi copy: heading campur EN / ID**
Sidebar berbahasa Indonesia, h1 sebagian Inggris: "Order" ( vs "Pesanan (Orders)" ), "Customer" ( vs "Database Customer" ), "AI Actions (Owner only)", "Audit Log (Owner only, append-only)", breadcrumb "Admin Portal / Inventory" ( vs "Inventori" ). Satu istilah per konsep ( R-31: alasan tertulis ).
Perbaikan: "Pesanan", "Pelanggan", "Aksi AI ( khusus Owner )", "Audit Log ( khusus Owner, append-only )" diterjemahkan konsisten; breadcrumb ikut h1.

**11. Footer "@2026"**
`layouts/default.vue` baris 54. Karakter "@" menggantikan "©" ( atau tulis "Toko demo, 2026" ). Salah ketik yang terlihat di tiap halaman publik.

### LOW ( Quality Locks )

**12. R-10 ( dicatat, dalam cap )** Total ada 3 permukaan blur di codebase: header default, header admin, header ChatWidget. Per-layout hanya 1-2 yang aktif bersamaan, jadi lolos dose cap; dicatat agar tidak bertambah.

**13. Badge channel `text-[10px] font-bold uppercase`** ( admin/index baris 198 ). Status nyata jadi lolos R-09, tapi 10px sangat kecil untuk dibaca. Naikkan ke text-xs bila direvisi.

**14. Em-dash di komentar kode** ( actions/[id] baris 130, index.vue baris 24 ). Bukan teks UI; R-02 secara hurufiah menyasar teks tampilan. Opsional dirapikan.

**15. Skeleton tersedia tapi tak terpakai** Loading berupa teks "Memuat…" yang jujur; cukup lolos R-27. Peningkatan opsional, bukan hutang.

## Yang sudah LULUS ( dicatat sebagai pass, dengan bukti )

- R-02 em-dash: storefront, chat, login, judul dokumen bersih ( dicek grep + DOM `document.body.textContent` ).
- R-17 / R-38 data: dashboard memakai data riil ( health, order, stok dari API ); tidak ada angka karangan; riwayat "buka sejak 2019" dari seed terdokumentasi.
- R-04 ikon: ListChecks ( antrean HITL ) dan Bot ( asisten chat ), alasan tertulis di design.md amendmen.
- R-08 panah: hanya untuk transformasi nilai ( harga diskon, stok, rentang tanggal ), didokumentasi.
- R-24 nav: semua link storefront dan sidebar menuju halaman nyata ( diklik satu per satu ).
- R-26 interaktif: chip prompt -> kirim -> balasan AI riil; disclosure spesifikasi; reset; login/logout; approve/reject flow ( halaman actions terverifikasi render ).
- R-32 keyboard: Tab mengikuti urutan visual, `:focus-visible` aktif ( terukur ), Button/Input memakai ring pengganti outline-none.
- R-03 overflow: 0px horizontal overflow di 390 / 512 / 820 / 1440 untuk storefront, chat, dan admin; tabel dibungkus `overflow-x-auto`.
- Zoom 200% ( viewport 512 pada layar 1024 ): tidak ada teks terpotong.
- antislop-code: tidak ada banner komentar, narasi langkah, TODO vagueness, emoji komentar.
- antislop-copywriting: tidak ada buzzword R-16, tidak ada rule-of-three paksaan, tidak ada klaim tanpa bukti; copy storefront spesifik dan bersuara.
